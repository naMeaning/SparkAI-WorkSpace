## 社群版

如果你平时会反复改图、做多款方案，或者素材散落在不同工具里，可以试试 SparkAI WorkSpace。它是一个免费的 Windows Agent 生图工作台：一个项目里管理素材、提示词、图片成果和来源关系，Agent 会根据当前画布继续生成、编辑、替换、做 variants 或分层处理，结果可以继续追问，不用每次从零开始。

接入也比较自由：

- 保留现有账号登录，更多 New API/Sub2API 站点的账号适配会继续扩展；
- 使用兼容的 New API、Sub2API 或其他 OpenAI-compatible 接口时，可以填自己的 Base URL + API Key；
- 本次通用体验包不要求 Pro 兑换码，模型费用仍按你选择的上游服务商规则计算。

目前是开发版邀请体验，公开 v1.0.9 尚未包含免费双接入改动。欢迎试用后反馈使用感受。

项目地址：<https://github.com/naMeaning/SparkAI-WorkSpace>
