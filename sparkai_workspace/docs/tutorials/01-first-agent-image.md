# Tutorial 01：第一次让 Agent 完成一张图

这条路径适合第一次使用 SparkAI WorkSpace 的用户。它只需要一个项目、一张你有权使用的图片，以及一个清楚的自然语言目标。

## 开始前

1. 安装 Windows 10/11 x64 版本并启动 SparkAI WorkSpace。
2. 在设置中完成账号登录，或配置你有权使用的 Base URL 和模型连接。自定义连接需要有效的 Pro License。
3. 新建项目并选择项目目录。项目目录会保存画布、受管图片、会话和导出结果。

不要用真实密钥或账号 Cookie 做截图；也不要把客户、未公开商品或私人照片上传到你没有确认过的数据处理规则的服务。

## 四步完成第一次请求

### 1. 导入图片

把图片拖到画布，或使用左侧素材栏的“+”。软件会把文件复制到当前项目的图片库，原始文件保持不变。需要纯文字生图时可以跳过这一步。

### 2. 选择处理角色

单击画布图片后，右侧 Agent 会同步当前选择。素材栏中的图片可以标成：

- **原图**：要被编辑、替换、重绘或作为生成基础的图片。
- **参考图**：提供风格、构图、颜色或内容参考的图片。

选择多个来源时，按素材栏中的序号说明它们的作用。例如：“原图 1 保留瓶身，参考图 2 只参考背景色”。参考图不能替代需要被编辑的原图。

### 3. 用结果来描述要求

在右侧 Agent 输入完整目标，尽量写清主体、场景、构图、比例和需要保留的内容。下面的提示词可以直接改写：

```text
保留原图中的白色陶瓷杯、杯口形状和印刷文字，放到明亮的早餐桌面上；
画面干净、留出右侧文案空间，不添加新的品牌标志，输出一张 1:1 商品主图。
```

没有原图时可以直接写：

```text
生成一张 1:1 的极简黑色耳机产品海报，深灰背景，柔和侧光，主体居中，
不要出现品牌名称、二维码或多张拼贴。
```

点击“发送给 Agent”或按 `Ctrl/Cmd + Enter`。如果输入以 `/` 开头，会被当作本地命令，例如 `/help`、`/status` 或 `/config`。

### 4. 检查结果并导出

Agent 的时间线会显示它正在做什么，图片工具卡会保留可展开的生成提示词。完成后：

1. 在画布或“专注”视图中查看生成图片组。
2. 确认原图仍在，新的图片通过来源关系连接到它。
3. 单击图片查看器或使用右键“另存为”导出；批量结果使用导出中心。

每次生成都可能向你配置的上游服务发送提示词、选定图片和请求参数，并可能产生费用。生成失败但上游已经接受请求时，不要立刻重复点击；先看时间线和脱敏诊断状态。

## Agent 和直接生图的区别

“发送给 Agent”适合需要理解上下文、观察原图、修改任务或连续对话的请求。底部的直接生图入口适合你已经确定提示词和参数、想跳过 Agent 对话的单次请求。两条路径都会使用当前项目的图片和配置，但只有 Agent 会维护本轮对话上下文与工具时间线。

## 结果不符合预期时

- 主体被改动：重新选择正确的原图，并明确写“保留主体结构和文字，只改变……”。
- 风格不对：把风格图片标成参考图，并说明它只用于颜色/材质/构图参考。
- 需要多个方向：在下一轮要求“生成 4 个独立方案”，不要要求拼成一张九宫格。
- 需要固定流程：把要求保存为需求节点或个人模板，下一篇教程会说明它不会因为连线而自动执行。
