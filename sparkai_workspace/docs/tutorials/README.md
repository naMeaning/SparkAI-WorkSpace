## 一条稳定的提示词结构

需要编辑或参考素材时，可以按下面的顺序写：

```text
基于 [原图编号] 完成 [动作]；
保留 [必须保留的主体、文字、比例]；
参考 [参考图编号] 的 [颜色/材质/构图]；
输出 [数量、比例、清晰度]；
不要出现 [明确排除项]。
```

例如：

```text
基于原图 1，把背景改成浅灰色摄影棚；
保留杯身轮廓、印刷文字和 1:1 构图；
参考图 2 只借鉴柔和侧光；
输出 3 张独立方案，不要拼成一张九宫格。
```

没有原图时可以省略第一句。素材栏中的“原图”表示要被处理的对象，“参考图”表示只借鉴信息；不确定时先在界面里确认编号，再发送请求。

## 每次执行前后都检查

执行前：

- 确认当前项目和选中的原图/参考图。
- 确认输出数量、比例、模型和服务商额度。
- 确认这次请求可以把哪些素材和提示词发送到上游服务。
- 批量、视频和平台导出先看预览，再明确点击执行。

执行后：

- 看 Agent 时间线和脱敏状态，不要用重复点击代替排查。
- 检查结果主体、文字、透明度、来源关系和输出格式。
- 确认结果已经保存到正确项目，再导出或继续编辑。
- 需要提交问题时只提供脱敏诊断，不提供 API Key、Cookie、连接文件、签名 URL 或完整本机路径。
