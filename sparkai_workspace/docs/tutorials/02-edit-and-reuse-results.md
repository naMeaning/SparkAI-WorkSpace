# Tutorial 02：编辑、批量、多款与可复用需求

SparkAI WorkSpace 把每次输出保存为新的成果。选择一张成果后继续处理，原图和已有结果都保留，画布上的来源关系可以回看。

## 你会完成什么

本教程适合已经完成第一次生成的用户。读完后，你可以：

- 选择正确的编辑语义，而不是用一条模糊请求覆盖原图；
- 在批量执行前冻结来源范围、数量和费用提示；
- 把稳定的要求保存为需求节点，并在明确执行后复用。

## 选择正确的操作

| 目标 | 在 Agent 中表达 | 结果行为 |
| --- | --- | --- |
| 文字生图 | “生成一张……” | 创建新的图片成果。 |
| 继续设计 | “保留主体，改成……” | 基于当前原图生成新的衍生成果。 |
| 替换元素 | “把杯子换成黑色，其他保持不变” | 原图保留，新图记录替换关系。 |
| 多款方向 | “基于这张图做 4 个独立风格” | 生成 4 张独立图片，不拼成一张图。 |
| 分层 PNG | “拆成背景、主体、文字和阴影图层” | 生成合成预览、独立同尺寸 PNG 图层和校验结果。 |
| AI 抠图 | “提取杯子主体，背景透明” | 先在界面中涂抹要保留的主体，再生成并验证透明度。 |
| AI 重绘 | “把选区里的天空改成日落” | 先涂抹需要修改的区域，再基于蒙版生成新图。 |

`replace`、`variants`、`layers`、`cutout` 和 `redraw` 是运行时的公开操作语义；一般用户不需要手写 schema，只要在 Agent 中描述目标并按提示完成选区即可。

## 让结果更稳定

1. 先单击要处理的成果，再发送编辑要求；没有选中成果时，Agent 不会把“画布”猜成原图。
2. 原图和参考图分开设置。原图说明“要处理哪张”，参考图说明“借鉴什么”。
3. 对商品、人物和文字，明确写出必须保留的结构、文字和比例。
4. 需要多个输出时说清数量和“独立图片”，避免模型把它们拼成一张海报。
5. 一轮结果完成后再继续下一轮；不要在创建结果未知时自动重试，以免重复计费。

## 批量 Goal

需要对一组原图执行相同操作时，可以在 Agent 输入框使用 `/goal`，或使用界面中的批量目标入口。发送前会展示冻结的来源范围、每张图的操作数和费用提示。只有你确认并发送后，任务才会向上游派发；运行中可以暂停、继续或停止，已经被上游接受的请求仍可能完成。

批量任务的安全做法是先选定明确的原图容器，再确认“每张图生成几张”。不要把参考图容器误当作原图范围，也不要把“全部图片”当作默认授权。

## 保存为可复用需求

当一条要求会反复使用时，可以从图片或图片容器创建需求节点：

1. 创建需求并写完整要求，例如“保持白底和主体比例，只替换包装颜色”。
2. 用连线把图片/容器接到需求的 SOURCE 或 REFERENCE 输入。
3. 保存后继续编辑，直到要求清楚。
4. 用户明确点击“执行”或在 CLI 中调用 `canvas.execute-requirement` 时才会生成。

连线只表示来源关系，不会因为接上就执行。重复执行同一个未修改需求时，软件会再次要求确认。保存为个人模板后，模板只会插入一份可编辑需求，不会自动调用模型。

## 会话和记忆

同一个项目可以新建多个会话；新会话保留画布成果，但隔离当前会话的消息和 FastMemory。清理当前聊天不会删除项目图片。需要彻底删除数据时，请在卸载或项目管理流程中使用明确的删除操作，并先备份重要项目。
