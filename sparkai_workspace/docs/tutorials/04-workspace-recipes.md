# Tutorial 04：电商、社媒与科研工作台示例

四个工作台共享同一个项目、画布、会话和 Agent。切换工作台只改变入口、插件和推荐上下文，不会复制画布、清空选择或自动调用模型。

## 电商：从母图到平台套图

1. 切换到“电商创作”，导入一张你有权使用的商品母图。
2. 在商品目录中填写商品、变体和 SKU；有品牌规范时，把 Logo、包装和风格参考图按商品归属关联。
3. 先使用套图工具预览平台规格，或对 Agent 说：“基于当前母图制作一套 Amazon 主图、细节图和场景图，保持包装文字不变。”
4. 检查每个结果的来源、语言和 SKU 归属，人工淘汰不合格候选。
5. 在导出中心选择 Amazon 或速卖通、格式和 SKU 范围，再确认打包。导出通过原生目录选择器完成，不接受脚本传入的任意目标路径。

套图执行会按计划产生多张图片；点击执行前确认上游余额和请求数量。平台规格检查通过不等于图片已经符合广告、商标或知识产权要求。

## 社媒：先做计划，再执行

1. 切换到“社媒创作”，选择小红书或抖音入口。
2. 输入主题、内容类型、比例、卡片数或镜头数，并可绑定当前画布原图。
3. 先保存结构化计划；计划本身不会调用模型或扣费。
4. 检查每张卡片/镜头的要求后，再明确执行。抖音计划中的视频请求会独立记录，创建状态不明时不会自动重建。
5. 生成完成后在专注视图复核图片和视频，再导出发布包。

## 科研：受管数据到可复核图形

1. 切换到“科研绘图”，通过文件选择器导入 CSV、TSV 或 TXT 数据。
2. 在数据列表确认字段、行列规模和哈希摘要，再创建图形计划；计划阶段不会运行代码或调用图片模型。
3. 选择 Python 或 R 后端、图形类型、研究主张和面板绑定。运行器只执行项目内受信生成脚本，不安装依赖，也不接受调用方直接传入的任意代码。
4. 明确执行后检查 PNG 预览、面板和受限日志；如果画布或计划版本发生变化，结果会保留在任务记录中，但不会被错误地宣称为当前画布成果。
5. 通过导出入口输出 PNG、TIFF、SVG 或 PDF，并在投稿/分享前人工复核统计表达和数据许可。

## 通用检查

- 工作台切换不会替代用户授权；任何生成、批量执行、视频创建或平台导出都要在对应按钮/命令处明确确认。
- 原始文件始终先复制进项目受管目录；不要把第三方服务返回的签名 URL 或本机绝对路径粘贴到公开文档。
- 生成内容、翻译、人物肖像、商标和科研数据的权利与合规性由使用者负责，发布前保留独立备份并人工审阅。
