# SparkAI WorkSpace AI 与上游费用说明

生效日期：2026-08-01
软件制作者：namean

## 1. 点击即授权请求

用户点击生成图片、一键生成套图、多语言翻译生图或确认 Goal 执行，即表示授权 SparkAI WorkSpace 向当前配置的 Base URL、中转站或模型上游发起请求。SparkAI WorkSpace 不再额外弹出独立费用确认框。

## 2. 计费主体

请求价格、免费额度、失败是否扣费、退款、发票、余额和账号限制由对应第三方服务商决定。SparkAI WorkSpace 仅展示能够获得的请求数量或费用提示，不代表代收费或对第三方账单作担保。

## 3. 小批量保护

高并发任务会先执行小批量探测，成功后再逐步放量；保护性失败会停止未派发请求。探测请求本身仍可能产生第三方费用，小批量保护不构成免计费承诺。

## 4. 用户建议

正式大批量执行前，用户应确认模型、图片数量、并发上限、第三方余额和价格。发现异常时应立即暂停或结束任务，并在对应第三方账单系统中核对请求记录。
