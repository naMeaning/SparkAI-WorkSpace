# iiimage Studio 1.0.1 发布说明

发布日期：2026-07-18

1.0.1 是首个具备完整应用内更新闭环的阶段发布版，保持“单一项目 Agent + 成果画布”的产品形态，不恢复工作流节点或子 Agent。

## 本次更新

- 增加应用内检查更新、签名与 SHA-256 校验、断点下载和重启更新。
- 兼容更新可在重启后直接生效；需要完整安装的大版本可在客户端完成验证码授权并下载安装包。
- 设置页改为显式保存，补充恢复默认和统一的软件更新中心。
- 安装器补充品牌欢迎页、安装路径选择、正式图标、桌面与开始菜单快捷方式。
- 修复正式环境 Agent 请求链路，生产 `gpt-5.6-sol` Responses 已通过真实 HTTP 验证。
