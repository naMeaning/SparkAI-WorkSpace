# SparkAI WorkSpace 隐私政策

生效日期：2026-08-01
软件制作者：namean

## 1. 适用范围

本政策适用于 SparkAI WorkSpace Windows 桌面软件。用户自行配置或登录的 Base URL、中转站、模型提供商、账号系统和电商平台属于第三方服务，并同时适用其各自的隐私政策。

## 2. 本地数据

SparkAI WorkSpace 默认在用户电脑或用户明确选择的项目目录中保存项目画布、托管图片副本、会话、设置、缓存、诊断摘要和更新文件。软件不会主动扫描项目范围之外的文件，也不会修改导入前的原始图片。

## 3. 网络传输

只有在用户执行登录、刷新模型、Agent 对话、图片生成、翻译生图、更新检查等联网操作时，完成请求所需的账号信息、文字、所选图片和请求参数才会发送到用户配置的服务。第三方可能记录请求、生成内容、用量、IP 地址或账单信息，具体以第三方规则为准。

## 4. 密钥与凭据

自定义 API Key 由 Electron 主进程调用操作系统安全存储进行加密，普通设置文件不保存明文密钥。账号会话、授权令牌和密钥不得写入项目文件、公开日志或公开 UI。用户不应向支持人员提交完整 API Key、Cookie 或账号密码。

## 5. 数据删除

默认卸载会保留项目与设置，防止误删创作数据。只有用户在卸载流程中明确选择删除本地数据时，SparkAI WorkSpace 才会清理内部项目库、会话、缓存、设置和运行日志。用户保存在外部目录的项目与原始图片不属于默认清理范围。

## 6. 用户责任

用户应妥善保护电脑账户、项目目录、API Key 和第三方账号，并对关键项目进行独立备份。发现异常请求或凭据泄露时，应立即停止任务并在对应服务商处更换凭据。

## 7. 政策变更

政策发生重大变化时，应通过软件更新说明或销售/支持渠道告知用户。继续使用更新后的版本，视为接受届时展示的政策。
