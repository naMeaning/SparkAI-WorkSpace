# 图片成果与分层 PNG 导出交付计划

更新时间：2026-07-12

## 一、目标

建立一条面向普通用户、无需理解内部路径的完整成果交付链：

1. 画布、图片容器、图片查看器、成果编辑器和分层查看器中的每张成果图都可右键“另存为”。
2. 图片导出使用明确的右键“另存为”、查看器下载和节点编辑器“另存为”；不再强行实现拖出 Windows，以免和画布内移动、归组、查看图片发生手势冲突。
3. 分层 PNG 仍由多个同尺寸、真实透明 PNG 节点组成；画布叠放态负责展示完整成图，专用查看器负责自由检查每一层。
4. 图层组支持一键展开、一键重组、显隐、独显、透视检查和非破坏性合并；合并结果是新的普通图片节点，原图层组保留。
5. 图层组可导出合成 PNG、结构化图层文件夹和真正保留图层的 PSD。

## 二、分层成果的显示方案

### 画布态

- 默认把同一组的独立图层节点放在相同锚点，透明 PNG 按层序叠加，因此视觉上是一张完整成图。
- 组号使用稳定的 `#NNN`，每层保留唯一节点 ID、层序、名称、角色、显隐、不透明度和混合模式。
- 叠放态只显示一套成图画板；图层通过外侧错层标签进入，避免六个完整节点壳互相遮挡。
- “展开到画布”把每层铺开为可单独拖动的节点；“图层重组”依据组 ID、层序和原锚点恢复，而不是依靠当前位置猜测。

### 分层查看器

- `合成`：按真实顺序和透明度叠加全部可见图层。
- `单层`：只显示当前层，适合检查抠图边缘、透明区域和漏画。
- `透视`：当前层保持 100%，其他可见层降低不透明度，直观看清层与层之间的覆盖关系。
- 右侧图层栏按 Photoshop 习惯以上层在上显示，提供眼睛显隐、当前层高亮、缩略图、层名与层序。
- 查看状态只影响显示；显隐状态可持久化，合并和导出明确使用当前可见状态或全部原始图层。

## 三、导出行为

### 单图

- “另存为”复制原始字节，不重新编码，不降低质量。
- 所有导出路径必须属于当前项目记录的受控资产，拒绝任意路径、符号链接越界和伪图片文件。

### 图层文件夹

导出目录包含：

- `00-合成预览.png`：作品预览（存在时）。
- `99-合成.png`：当前可见图层的合成结果。
- 按层序命名的独立 PNG，例如 `01-背景.png`、`02-主体.png`。
- `layers.json`：组号、画布尺寸、层名、层序、角色、显隐、不透明度和混合模式；不泄露项目内部绝对路径。

写入使用同目录暂存文件夹，所有文件成功后再原子提交；中途失败不得留下半成品目录。

### Photoshop PSD

- PSD 画布尺寸与 PNG 图层完全一致。
- 保留中文层名、上下层序、RGBA/Alpha、显隐和不透明度。
- 在后台 Worker 中生成，避免大图阻塞界面。
- 写入临时文件后重新读取并校验层数、层名、尺寸、透明像素和合成像素，校验成功才替换目标文件。
- 暂不支持的非普通混合模式必须明确阻止导出，不能静默生成视觉错误的 PSD。

## 四、非破坏性原则

- 另存、拖出、合并和导出都不得覆盖用户原图或已有画布成果。
- 合并产生新的内容寻址文件和新的普通图片节点；多次合并不会回写旧节点。
- 删除一个图层后重新编号；只剩一个图层时降级为普通图片，避免留下伪图层组。
- 历史单节点图层栈加载时迁移为独立图层节点；残缺组在重组或导出前修复/阻断，不能导出损坏文件。

## 五、验收矩阵

1. 严格 TypeScript（含未使用参数/变量）通过。
2. Electron 主进程、preload、PSD 主模块和 Worker 语法检查通过。
3. 正式构建通过。
4. PSD 自测通过：中文层名、顺序、透明/半透明像素、合成像素和磁盘回读一致。
5. AIDebug 分层专项通过：六个独立节点、透明图层、单层拖出、展开/重组、显隐持久化、删除降级、非破坏合并和三类导出。
6. 单图另存副本与源文件 SHA-256 完全一致。
7. 画布内标准单图通过真实 Pointer 手势落入另一图片的明确吸附区后，执行非破坏视觉归组；来源节点与 `parentId/relationType` 全部保留。
8. Windows 拖出入口、preload bridge 和主进程旧 IPC 均不存在；普通拖动不会意外触发系统文件拖放。
9. 图片集合、默认 GUI 和 Agent-only 回归全部通过。
10. 如果验收机器没有 Photoshop 或可用浏览器，必须如实记录“未做真实 Photoshop 打开”，不能用内部自测替代该声明。

## 八、2026-07-13 普通图片 PSD 闭环补齐

- 任意普通 PNG、JPEG、WEBP 成果均可导出单栅格图层 PSD；分层 PNG 仍走原有多图层 PSD，不会被误降级。
- 前端入口已覆盖标准节点右键、图片容器/批量组的具体资产右键、统一成果编辑器和图片查看器。容器资产通过真实 `nodeId + assetIndex` 映射，第二张图片导出的图层名明确为“图片 2”。
- 保存对话框在任何图片下载、物化或格式转换前打开；用户取消不会访问远程图片，也不会创建转换缓存。
- PNG 不重新编码；JPEG/WEBP 使用独立 `sharp` 子进程转为同尺寸 RGBA PNG，再复用现有 PSD Worker、临时文件、写后读回和像素校验链路。
- 转换与 PSD Worker 均以“结果已收到且进程正常退出”作为完成条件；取消、超时和异常退出会二次清理 staging，损坏图片返回用户可理解的中文错误。
